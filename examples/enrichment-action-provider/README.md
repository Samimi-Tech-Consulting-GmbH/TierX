# Deterministic enrichment-action provider

This container implements the signed `v1` provider contract for testing. It
returns an `OBSERVED` result derived from a small allowlist of normalized ECS
fields. It performs no port scan, credential check, inference, or response
action.

Required environment:

- `EXAMPLE_ENRICHMENT_ACTION_SECRET`: the copy-once secret generated by TierX.
- `EXAMPLE_ENRICHMENT_ACTION_CODE`: defaults to `example-observer`.
- `EXAMPLE_ENRICHMENT_ACTION_DATA`: defaults to `/data/deliveries.json`.

Mount `/data` persistently so repeated delivery IDs return the original result.
Publish it only behind an HTTPS reverse proxy; the container itself listens on
private port 8080.
